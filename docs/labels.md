# Suggested GitHub labels for this change

Please create these labels in the GitHub repository (they are not created automatically by this script):

- frontend
- backend
- devops
- infrastructure

If you have repository admin access you can create them via the GitHub UI or with the gh CLI:

# Using gh (GitHub CLI)

# gh label create frontend --color F29513 --description "Changes to front-end/UI"

# gh label create backend --color 0E8A16 --description "Backend/API changes"

# gh label create devops --color 0052CC --description "CI/CD and deployment changes"

# gh label create infrastructure --color 5319E7 --description "Infra / docker / cloud"

Apply them to the PR once labels exist.

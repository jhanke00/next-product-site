# Shopping Cart Feature

## Overview
This feature adds shopping cart functionality to the application, allowing users to manage products before checkout.

## Features
- Add products to cart
- Update product quantity
- Remove items from cart
- View total items and total price

## Tech Stack
- Next.js
- React
- Redux Toolkit
- TypeScript

## How It Works
- Products can be added to cart
- Cart state is stored centrally for global access
- Cart updates reflect instantly across the UI

## Folder Structure
- /components – Cart UI components
- /store –  state management
- /catalog – homepage

## How to Run

npm run dev
